# AUNG Gas Solutions — POS & Inventory PWA

An offline-first, mobile-friendly Point of Sale (POS) and Inventory Management web application built specifically for AUNG Gas Solutions on Zangama Road, Thaketa Township, Yangon, Myanmar.

## Features
- **Offline-First IndexedDB Persistence**: Operates entirely in your Android browser without internet dependency.
- **Progressive Web App (PWA)**: Installable directly on Android home screen.
- **Burmese Interface**: Tailored to local terminology and business operations.
- **Navy & Orange Branding**: Styled to professional standards.

## GitHub Pages Deployment Instructions
1. Create a repository named `AUNG-pos` on GitHub.
2. Upload all project files maintaining the exact folder structure (`css/style.css`, `js/db.js`, `js/dashboard.js`, `js/app.js`, `index.html`, `manifest.json`, `sw.js`).
3. Go to repository **Settings** -> **Pages**.
4. Set source to **Deploy from a branch** (`main` / `root`).
5. Access your live app URL on your Android phone and select "Add to Home Screen".
